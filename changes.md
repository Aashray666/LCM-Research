## Why These Results Are Not Yet Publishable

### 1. 1 Epoch = Underfit Model

`MultipleNegativesRankingLoss` (MNRL) typically requires **3–5 epochs** to converge when fine-tuning sentence transformer models. Running for only 1 epoch means:
- The model has seen each training pair only once
- Gradient updates are minimal relative to the model's capacity
- The **true performance ceiling is unknown** — the 0.709 MRR is a floor estimate

**What reviewers will ask:** *"Did the model converge? What does the training loss curve look like across epochs?"*

### 2. 1,998 Pairs Is Borderline

With 24,166 chunks available, 1,998 training pairs (~8% coverage) is workable but thin. Comparable published retrieval fine-tuning experiments typically use:
- BEIR training sets: 5,000–50,000 pairs
- Domain-adapted models: 3,000–10,000 pairs minimum

The risk is that the model overfits a narrow slice of the biomedical vocabulary rather than learning robust domain-level representations.

**What reviewers will ask:** *"How sensitive are results to the number of training pairs? Did you run an ablation?"*

### 3. No Variance Estimate (Single Seed)

A single fine-tuning run can be lucky or unlucky depending on the random initialization and batch ordering. Standard practice for any ML paper is:
- Run **3 seeds** minimum (e.g., seeds 42, 43, 44)
- Report **mean ± standard deviation** for all metrics
- Ensure the improvement is statistically consistent, not a one-off

**What reviewers will ask:** *"Is this improvement statistically significant? What is the variance across runs?"*

### 4. No External Benchmark Evaluation

The current evaluation uses **synthetic test pairs** generated by the same LLM that generated training pairs. This means:
- The test distribution partially matches the training distribution
- Results may be inflated relative to real user queries
- No connection to established biomedical IR benchmarks

Running on **BEIR/NFCorpus** or **BioASQ** provides an independent, distribution-shifted evaluation that reviewers will expect.

**What reviewers will ask:** *"How does the model perform on standard benchmarks outside your own synthetic test set?"*

### 5. No Ablation Study

The paper currently cannot answer:
- Does MNRL help more than TripletLoss? (yes, by design, but needs empirical support)
- Does the number of epochs matter? (unknown)
- Does the number of training pairs matter? (unknown)
- Do hard negatives help over random negatives? (unknown)

Ablations are standard in retrieval fine-tuning papers and make the contribution much stronger.
